# Ferris Wheel

A responsive animated web page built with **HTML** and **CSS** as part of my **Responsive Web Design Certification** from FreeCodeCamp.org. This project demonstrates layout, styling, and animation skills using core front‑end technologies.

---

## Overview

This repository contains the source files for a Ferris Wheel‑themed web page with engaging animation. The animation and layout showcase the use of HTML and CSS to create dynamic, responsive visual effects without JavaScript.

The project was developed as coursework to practice responsive design principles and CSS animation techniques.

---

## Features

✔ Animated Ferris wheel element using CSS  
✔ Responsive layout adapting to different screen sizes  
✔ Clean, semantic HTML structure  
✔ Custom CSS styles and animation keyframes

---

## Technologies Used

- **HTML5** – page structure and content  
- **CSS3** – styling, responsive layout, and animation  

---

## How It Works

- **`index.html`** contains the page structure and elements.  
- **`styles.css`** defines visual styles and animations using CSS keyframes.  
- The Ferris Wheel effect is created entirely through CSS animation and layout techniques, demonstrating custom animation without JavaScript.

This project highlights foundational front‑end skills in web design and animation, emphasizing visual presentation and responsiveness.
